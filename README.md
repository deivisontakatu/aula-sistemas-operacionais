# Sistemas Operacionais — ADS | FATEC Itapetininga

Repositório de apoio à disciplina **Sistemas Operacionais**, com materiais teóricos, atividades, exemplos e manuais para acompanhar as aulas, revisar conceitos e aplicar os fundamentos dos sistemas operacionais na prática.

> **Objetivo:** compreender como um sistema operacional gerencia os recursos do computador e conectar os conceitos estudados a situações reais, como execução de processos, gerenciamento de memória, arquivos, dispositivos e virtualização.

## 🎯 Competências trabalhadas

Ao longo dos conteúdos e atividades, a disciplina busca desenvolver a capacidade de:

- Explicar o papel do sistema operacional na relação entre software e hardware.
- Identificar componentes e responsabilidades do kernel.
- Compreender processos, execução de programas e gerenciamento de recursos.
- Entender fundamentos de gerenciamento de memória.
- Trabalhar com arquivos, diretórios, dispositivos e permissões.
- Comparar diferentes tipos de sistemas operacionais.
- Preparar e utilizar ambientes virtualizados.
- Aplicar conceitos em atividades práticas, com documentação técnica clara.

## 🧑‍🏫 Como utilizar este repositório

1. **Acompanhe a sequência dos conteúdos** e consulte os arquivos correspondentes à aula.
2. **Leia o enunciado completo** antes de iniciar uma atividade.
3. **Registre suas dúvidas** e utilize exemplos e referências para aprofundar os conceitos.
4. **Teste os procedimentos** no ambiente indicado e valide os resultados.
5. **Documente o que foi realizado**, incluindo comandos, decisões e limitações relevantes.
6. Para trabalhos com GitHub, mantenha o repositório organizado e registre a evolução do projeto com commits claros.

### Ferramentas e ambientes

Conforme a atividade, poderão ser utilizados:

- **Linux e terminal** para explorar comandos e recursos do sistema.
- **Oracle VirtualBox** para executar sistemas operacionais em máquinas virtuais.
- **Git e GitHub** para versionamento, colaboração e entrega de projetos.
- **Markdown** para elaborar documentação técnica.

Use as ferramentas exigidas ou recomendadas no enunciado de cada atividade.
